# Dharohar React

React + Vite conversion of the original single-file Dharohar landing page.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/pages/Home.jsx` — page composition
- `src/components/` — Navbar, Hero, HowItWorks, Features, Sites, WhyDharohar, API, CTA, Footer
- `src/styles/global.css` — original design system and responsive styles
- `public/assets/` — extracted app preview images
- `src/main.jsx` — React bootstrap + scroll reveal/trail interactions
